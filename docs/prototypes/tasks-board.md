用户的要求：以 Linear 的泳道看板为结构模板，视觉用 Cloudflare 新版官网的简洁线条风格；每张卡片要有显式的「跳转到原 workspace 对应 tab」按钮；模型和思考等级不能被截断；移动端用 tab 切换泳道，一次只显示一个泳道；卡片要显示项目、workspace、分支、文件夹和标签，且不能挤、不能截断；卡片显示哪些字段可在插件设置里配置；状态用 Paseo 官方的状态图标；手机上一行放不下就换行，不必要的信息隐藏到长按详情。

## 原稿规格摘要

完整规格见原稿画板 06，这里只摘移植时最常查的部分。`mix(A, B, p) = A × p + B × (1 − p)`，sRGB 逐通道线性混合，在 React Native 侧预计算成不透明色。

### 派生颜色

宿主 token 之外只新增下面这些派生色，全部由宿主 token 推出。

| token | 公式 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- | --- |
| dotGrid | mix(foregroundMuted, surface0, 22%) | `#dedee1` | `#353539` | 点阵 1px，间距 16 |
| borderStrong | mix(foregroundMuted, border, 35%) | `#b8b8be` | `#54545b` | 卡片悬停描边、未勾选框 |
| accentSoft | mix(accent, surface0, 12%) | `#e7eefb` | `#222836` | 开关开启底、允许按钮悬停 |
| accentRing | mix(accent, surface0, 28%) | `#c8d7f6` | `#2f3d5b` | 焦点外环 3px |
| highlight | mix(accent, surface0, 8%) | `#eff3fd` | `#1f232d` | 父子跳转高亮底（1s） |
| dangerSoft | mix(statusDanger, surface0, 10%) | `#fbecec` | `#2e1f21` | 确认停止按钮底 |
| popoverShadow | surface0 亮度 ≥ .5 ? 黑 12% / 6% : 黑 50% / 35% | | | `0 8 24 −6` + `0 2 6 −2`，仅菜单、详情、Toast |
| scrim | surface0 亮度 ≥ .5 ? `rgba(0,0,0,.32)` : `rgba(0,0,0,.56)` | | | 手机底部 sheet 遮罩 |
| tagChip | 底 surface0 · 描边 border · 字 foregroundMuted | `#ffffff` / `#e2e2e6` | `#18181b` / `#2e2e33` | 标签 chip，随主题 |
| tagDot | 标签数据色，不随主题，如 violet `#8b5cf6`、red `#ef4444` | | | 标签色点 6 × 6 |

`statusSuccess` 保留未用。scrim 是原稿新增的固定色，宿主主题里没有对应 token。标签色点和项目头像底色是「数据色」，浅深主题同值。

### 卡片

卡片按组排版，组与组之间用留白分开，不再逐行截断；每条信息完整显示，放不下就折行（最多 2 行）。

| 元素 | 规格 |
| --- | --- |
| 卡片 | 宽 100%（列宽 320 时约 298），卡片间 10；内边距 12 14，圆角 8，1px border；悬停 borderStrong + 底 surface1；焦点 accent + 3px accentRing |
| 头部组 | 状态槽 16 × 20 + 6 + 标题（13/600/20，最多 2 行）+ 跳转按钮；标题下方是副标题「Claude · Opus 5.5 · High」，12/400/18，整行 foregroundMuted，品牌位图缩到 12 × 12 内联在 agent 名前；头部组不放行首图标 |
| 位置组 | 与头部组间隔 10，不用分隔线；行高 20，组内行间 4；行首图标槽 16（与状态槽同列），只在这一组使用行首图标 |
| 位置组第一行 | 项目头像 12 × 12（1px foregroundMuted 描边、无底色、首字母 8/600）+「项目 › workspace」；项目名 foreground，其余 foregroundMuted；workspace 与项目名或任务标题相同时只显示项目名；放不下整段折行 |
| 位置组第二行 | GitBranch 12 + 分支（可接 Git 状态）；文件夹满足显示条件时同行接「· Folder + 文件夹」，放不下折行；没有分支时行首改为 Folder |
| 底部组 | 与上一组间隔 8，高 20；左边标签 chip（高 20，色点 6 + 名称 11/400，最多 2 个，其余 +N），右边计时（12 tabular-nums，待输入用状态色加 clock 图标）或「约 Xm · N 分钟前」 |
| 列特有区块 | 权限请求、上下文条、子任务、失败原因；与上方之间 1px 虚线，左右出血到卡边，区块内上留 10 |
| 跳转按钮 | ArrowUpRight，24 × 24（手机 36 × 36），图标 14（手机 18）；默认透明描边，悬停 1px border + 底 surface2 + 图标 foreground；tooltip「在 workspace 中打开 [Enter]」悬停 400ms 出现 |
| 子任务行跳转 | 22 × 22（手机 32，行高 36），行悬停时出现，手机常驻 |
| 去重 | workspace 名等于项目名或任务标题时不显示；文件夹等于项目名、workspace 名或分支名（`/` 视作 `-`）时不显示；开启「完整路径」时路径代替文件夹 |
| 行收起 | 字段被设置关掉或没有数据时整行不渲染；位置组全空时整组连同上方留白一起收起；标签和计时都关掉时底部组收起；精简密度只留头部组和底部组的计时 |

### 列与看板

- 列 `flex: 1 0 320px`，四列放不下时看板横向滚动；列头右侧折叠按钮把列收成 40px 竖条（状态图标 + 竖排列名 + 数量），点整条展开。列间 1px 竖线，列底为 surface0 叠点阵。
- 列头高 40，底部 1px 虚线（4/3），左侧是官方状态图标；列名 13/500，数量 12/400 tabular-nums。
- 竖线与列头底线的交点处放 6 × 6 角标（1px border、填 surface0、圆角 1），即 Cloudflare 风格的网格交点。
- 列内容区内边距 10，卡片间距 8。

### 交互规则

- 停止：悬停显示（触屏常显）；点一次进入「确认停止」danger 态，3 秒内再点才执行，超时、移出或 Esc 复原。父任务下拉可选「仅停止此任务 / 连同子任务一起停止」。停止后卡片进入待查看，原因行「已手动停止」。
- 允许 / 拒绝：处理第一条请求；还有剩余就换下一条并重置等待计时，没有剩余则卡片回到运行中。
- 打开卡片：显式入口是标题行跳转按钮、子任务行按钮、详情浮层「打开 tab ↗」、提问卡「去回答 ↗」；点卡片主体或聚焦后 Enter 也打开。待查看的未读卡打开后标为已读，移入已完成；失败卡保留到重新运行。
- 详情浮层：悬停 450ms 显示在卡片右侧 8px；移出卡片 150ms 后关闭，期间移入浮层则保持。
- 键盘：J/K 或 ↑↓ 列内移动，H/L 或 ←→ 跨列（跳过空列），Enter 打开，Esc 取消确认，/ 聚焦搜索。

### 动效

所有过渡不超过 200ms，无回弹；循环动画只有运行中列图标（1600ms 旋转）和骨架（1200ms 呼吸），系统开启「减弱动态效果」时关闭。悬停、按钮、焦点、确认停止类过渡都是 120ms ease-out；菜单与详情出现 160ms `cubic-bezier(.2,0,0,1)`，消失 100ms ease-in。

### 移动端（宽 390）

- 顶栏高 52，「Tasks」17/600 + 总数；搜索、过滤按钮点击区 44 × 44，过滤角标显示生效条件数。
- 泳道 tab 栏高 44，四等分，吸顶；底部 1px border 通栏，选中项 2px accent 下划线（宽 25% − 24，单一元素横移）。未选 15/500 foregroundMuted，选中 15/600 foreground；待输入计数大于 0 时始终 warning。
- 一次只显示一个泳道，卡片宽 366，间距 10，内边距 14 16，底部留 34 的安全区。
- 手机卡片和桌面一样分组：头部组（标题 16/600 + 副标题 14）、位置组（项目 › workspace、分支）、底部组（标签 + 计时），再接操作栏（按钮高 40，等宽平分）；组之间留 12，信息行高 22。一行放不下就换行；文件夹、完整路径、Git 状态、关联 PR、项目图标默认隐藏到长按详情 sheet。
- 左右滑动：水平位移 ≥ 56 且 |dx| ≥ 1.5 |dy|，首尾不循环；触发后 350ms 内吞掉卡片点击。长按 450ms 打开详情 sheet，移动超过 8px 取消。
- 切换动效 200ms `cubic-bezier(.2,0,0,1)`：下划线横移；旧内容淡出并位移 24（120ms），新内容反向进入（200ms）。
- 默认泳道：有待输入停在待输入，否则停在运行中；会话内记住上次选择。
- 底部 sheet：最大高 80%，顶圆角 16，把手 36 × 4；进入 200ms，退出 160ms；下滑或点遮罩关闭。主按钮高 44、全宽、圆角 22，只在 sheet 底部用实心按钮。

## 移植时要注意

- 原稿用 HTML/CSS 演示，落地是 React Native 插件：`position: sticky`、`touch-action`、`box-shadow` 等要换成 RN 的对应写法，阴影在 Android 上要单独处理。
- 提示词里给的 warning 浅深参考色 `#c98a12` / `#e0a53a` 是出稿用的估计值，实现时一律读宿主的 `statusWarning`。
- scrim 是固定色，不随宿主主题变化。
- 原稿里的品牌标识是位图占位，实现时复用 `server/mark-bitmaps.ts`。
- 标签颜色和项目图标要等上游 [getpaseo/paseo#7482](https://github.com/getpaseo/paseo/pull/7482) 合入：它给插件的 `PaseoApi` 加了 `workspaces.listLabels()` 和 `projects.icon()`。标签颜色是协议里的颜色名（violet、red 等），按原稿的 tagDot 色值映射；项目有图标时用 `projects.icon()` 的图，没有时才用首字母头像。合入前，标签用中性色点、项目用首字母头像。
- 原稿里的示例 PR 编号（含 #218）、领先落后提交数、路径和项目头像色是 Claude Design 编的。
- 状态图标照搬 Paseo 侧边栏（`packages/app/src/components/sidebar/sidebar-workspace-row-content.tsx`、`components/status-ring/`），颜色是 Paseo 内部的 statusDot 色带：运行中 `#268ae0` / `#5caaf6`、等待 `#b37824` / `#db932e`、未看 `#299f51` / `#35c264`、失败 `#f12e2f` / `#f7796d`。插件主题没有这组颜色，等待、失败、未看可用 `statusWarning`、`statusDanger`、`statusSuccess` 近似，运行中的蓝色只能按 surface0 明度内置常量。
- 原稿里的 workspace 类型图标是按路径推断的，实现时读 workspace 描述里的 `workspaceKind`（`local_checkout` 用 Monitor，`worktree` 用 FolderGit2，其余用 Folder）。
