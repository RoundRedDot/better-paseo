用户的要求有三条：
- 把手机上「长按 Block 弹出居中浮层」改成「单击 Block 打开底部抽屉」，交互参照任务详情 sheet；
- 平板重新设计；
- 覆盖从手机、平板到桌面的所有尺寸。

## 点击模型

| 操作 | 触屏（手机、平板、触屏 Web） | 指针（桌面、iPad 触控板） |
| --- | --- | --- |
| 单击行身 | 打开详情，形态按断点决定 | 打开右侧面板。设置里可以改回「单击 = 原地展开」 |
| 单击 chevron 区 | 原地展开或收起，热区宽 44、高同行高 | 原地展开或收起，热区宽 28；⌘ / Ctrl 加单击行身效果相同 |
| 长按 500ms（移动小于 10px）/ 右键 | 操作菜单：打开详情、在时间线中展开、复制（复制什么按工具决定） | 右键弹出同一菜单 |
| 悬停 | 无 | 保留现有悬停预览（1s，可设 0–10s）；面板已在显示这一行时不弹 |
| 无正文的行 | 不显示 chevron，单击只有 120ms 按压态，长按菜单只有「复制标题」 | 无悬停预览，单击无反应 |
| 读图片的行 | 单击直接打开图片查看器，长按菜单首项为「查看图片」 | 同左 |
| 面板打开时单击其它行 | 手机点在蒙层上会关闭抽屉；平板的浮动面板和右侧面板会直接切换内容 | 直接切换内容 |
| 单击当前行 | 手机上被蒙层覆盖，点不到 | 关闭面板 |

## 断点（W 为窗口宽或 Modal 宽，S 为 W 减去宿主侧栏宽，P 为右侧面板宽，回差 16）

| 窗口 | 形态 |
| --- | --- |
| W < 600 | 底部抽屉，贴边，上圆角 16，有蒙层 |
| 600 ≤ W < 960 | 浮动底部面板，宽 min(W − 32, 760)，居中，四角圆角 16，距底 12 加安全区，无蒙层 |
| W ≥ 960 且 S − P ≥ 400 | 右侧面板，宽 P = clamp(0.36W, 420, 640)，贴右，高度贴满，左边框 1，无蒙层，背后的行可以点 |
| W ≥ 960 但 S − P < 400 | 浮动底部面板，例如 iPad 11 寸横屏展开宿主侧栏时 |
| 手机横屏（高 < 500） | 右侧面板，宽 400 |

- 换档时保留当前 Block，以及正文的滚动位置、换行和渲染 / 原文状态。动画是旧形态 120ms 淡出、新形态 160ms 淡入。
- 抽屉或浮动面板的全屏档换到右侧面板时，退回初始档。
- 拖动窗口大小的过程中不换档，停下 150ms 后再判断。

## 抽屉本体

- **档位**：初始高 = min(内容高, 0.58 × 可用高)。只有内容超过半屏才有全屏档，全屏高 = 可用高 − 8。3 行输出约 266，2000 行输出打开在 462。
  - 可用高 = 屏幕高 − 顶部安全区。
  - 自适应档只有一档，上拉时有 0.3 阻尼并回弹。
- **头部**：触屏高 52、桌面高 44。
  - 左边是 28 的图标块。标题 14/600（命令类 13 等宽），单行，单击后展开为多行（最多 4 行）。下面一行副标题 12，内容是状态、时长和序号，例如「6 / 15」。
  - 右边是 ‹ › × 三个按钮，触屏 36、桌面 28。
- **工具栏**：触屏高 44、桌面高 36。
  - 左：换行、渲染 / 原文、合并行分页器。
  - 右：复制（主操作加下拉）、全屏（右侧面板里是宽面板），对应原来的最大化。
  - 复制的内容按工具决定：
    - Bash：命令、输出或全部；
    - Read：内容或路径；
    - Edit：diff、新内容或路径；
    - Search：结果或匹配文件列表；
    - Fetch：Markdown 或 URL；
    - Agent：结果或整段对话；
    - 思考、提问、todo：Markdown。
- **正文**：
  - 路径行 12，等宽，muted；
  - 代码 12/18，行号列宽 40，行号字号 11，隔行 surface1；
  - diff 行号列宽 36（桌面双列），符号列宽 16；
  - Markdown 14/22；
  - 错误单独一节，上边框，标题 danger 色。
- **运行中的 Block**：自动跟随到底部。离底超过 48 停止跟随，出现「回到最新 · N 行新输出」胶囊；回到离底 8 以内恢复跟随。

## 切换 Block

- 范围是整个会话里可预览的 Block。合并行算一个，无正文的行跳过。
- 切换方式：在头部横滑，或点 ‹ ›。位移超过 25% 宽或速度超过 0.5px/ms 就切换。首尾 Block 有 0.3 阻尼并回弹。
- 时间线同步滚动 240ms，让当前行落在可见区内，距面板顶不小于 24。
  - 当前行标记：accentSoft 底，左侧 2 × (行高 − 10) 的 accent 竖条，圆角 6。标记只在面板打开时显示，关闭后保留 1.2s 再淡出。
  - 宿主列表已滚到底、没法再上移时不强求，靠头部的标题提供上下文。

## 手势

| 手势 | 阈值 | 说明 |
| --- | --- | --- |
| 方向锁定 | 移动 10px 后判断，\|dx\| > 1.2\|dy\| 为横向 | 判断后整个手势不再改 |
| 竖拖切档 / 关闭 | 位移 > 64 或速度 > 0.5px/ms | 只在把手、头部上，或正文滚到顶后继续下拉时生效 |
| 全屏档直接关闭 | 下甩速度 > 1.2px/ms | 否则回到初始档 |
| 横滑切换 Block | 位移 > 25% 宽或速度 > 0.5px/ms | 只在头部生效；正文横滑只滚动代码 |
| 宿主侧滑让位 | 起点 x < 20 的横滑交给宿主 | 抽屉打开时手机有蒙层，宿主列表收不到触摸 |
| 工具栏 | 只响应单击 | 不参与拖动 |

## 动画（统一缓动 cubic-bezier(0.2, 0, 0, 1)）

| 动作 | 时长 | 做法 |
| --- | --- | --- |
| 抽屉 / 浮动面板打开 | 280ms | translateY 100% → 0，蒙层 200ms 线性淡入 |
| 切档 | 240ms | 手势松开时 = clamp(剩余距离 / 速度, 160, 240) |
| 关闭 | 200ms | 无 |
| 右侧面板打开 / 关闭 | 240ms / 160ms | translateX 24 → 0，同时淡入 |
| 切换 Block | 220ms | 旧内容横移 ∓25% 并在前 120ms 淡出，新内容从 ±24 移入；高度变化 240ms |
| 长按菜单 | 160ms | scale 0.96 → 1，原点在行上 |
| 减少动态 | 一律 120ms | 只改透明度，时间线同步直接跳到位 |

## Claude Design 提出的取舍

- **列表末尾的行会被抽屉盖住**：宿主列表滚到底后没法再上移，靠头部的标题提供上下文。手机画板里，时间线故意画在还没滚到底的位置。
- **桌面单击改了行为**：由「原地展开」改为「打开右侧面板」，是它的建议，可在设置里改回。
- **深色覆盖不全**：平板和桌面只画了浅色。

## 移植前要核对

- **右侧面板背后的行可以点**：要求 Modal 的空白区域把触摸传给下面的时间线。宿主 Modal 能否做到，要在 iOS 和 Android 上实测；原稿只写了「透明 Modal 加 pointerEvents="box-none"」。做不到的话，平板只能加蒙层，点背后的行也就不能直接切换。
- **把触摸让给宿主**：横滑起点 x < 20 时让给宿主、正文滚到顶后把下拉交给抽屉，都要在宿主的手势体系里验证（见 memory：宿主手势会抢插件的拖动）。
- **桌面单击改为打开右侧面板**：这改变了已有习惯，需要用户确认。
- **设置项**：「单击 = 原地展开 / 打开详情」需要新的设置项和设置页文案。
