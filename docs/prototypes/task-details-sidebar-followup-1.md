修改：侧边栏不需要浮动显示，去掉「窄窗口改成覆盖在看板上的抽屉」这个模式。侧边栏在任何宽度下都和看板在同一层、内嵌在右侧，不盖住看板、不加遮罩、不做滑入抽屉。

窄窗口的规则改为：
1. 剩余宽度放不下两列时，和 1280px 一样，泳道区横向滚动，侧边栏保持内嵌。
2. 拖拽宽度的范围不变（340–520）；窗口变窄时侧边栏先缩到 340，再让泳道区滚动。
3. 只有窗口窄到泳道区连一列（300 + 左右边距）都放不下时，侧边栏才自动收起（不是变成浮层）。这只是临时收起，用户的开关偏好不变，窗口变宽后自动恢复；收起期间开关按钮显示一个小提示说明原因。阈值留 24px 回差。
4. 抽屉相关的动画参数（滑入 220 / 滑出 160）、Esc 关闭抽屉、「抽屉里不自动切换」等规则全部删除；Esc 只保留「返回上一张 → 取消钉住」。
