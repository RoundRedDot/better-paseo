用户的要求：桌面端去掉卡片悬停浮层，改成 Linear 式常驻侧边栏，可用按钮开关；风格对齐 Linear；宽屏内嵌，放不下才浮动；顶部是四种状态的统计卡，选中卡片后下面才出现详情卡片；手机和平板针对触屏单独设计。

画板：1 宽屏无选中 / 选中；2 侧边栏各状态（浅、深）；3 桌面交互与窄窗口；4 平板（iPad 横竖屏、折叠屏）；5 手机；6 移植规格。

## 视觉（从 Linear 截图量取）

- 每块是独立卡片：card 底（浅 surface0、深 surface2）、1px 边框、很淡的阴影、圆角 12、卡片间 8。文字距卡片边 12。
- 顶栏圆形按钮：桌面直径 28，触屏 36、热区 44；侧边栏开关打开时 surface2 实底。
- 分段胶囊：高 28、圆角 14、间距 6，未选中描边，选中灰底。
- 列表行 40（头像 20）；属性行 36，标签列 80 + 8 间距。

## 内容结构

- 统计卡永远在最上面：标题「107 个任务」，四格一行（待输入、运行中、待查看、已完成），状态图标与泳道头一致，数字 20/600 tabular。待输入 > 0 时数字用 warning 色并加淡边框；已完成标出时间范围（24 小时）。点某格：看板滚到该泳道。
- 无选中：统计卡下面是分组卡（Agent / 项目 / 标签 分段 + 计数列表，点一行加入筛选）。
- 有选中：分组卡让位，依次是头部卡（状态、标题、元信息、动作按钮，右上 pin / ⋯ / ×）、位置卡（属性行）、子任务卡、用量卡。
- 统计卡和头部卡固定，动作按钮始终可点；位置、子任务、用量在下方滚动。侧边栏高度 < 640 时统计卡收成单行。

## 内嵌与浮动（B = 看板容器宽，不含宿主侧栏）

- B ≥ 1020 内嵌，B < 996 浮动，中间 24px 回差保持当前模式。内嵌时宽度可拖拽 340–520，变窄先缩到 340。
- 浮动面板盖在看板右侧，不加遮罩，看板宽度不变；看板右侧留出面板宽的滚动余量，让最后一列能滚出面板。点面板外或 Esc 关闭。
- 浮动时悬停只显示底色、不切换内容，只在单击和 J/K/H/L 时切换。
- Esc：返回上一张 → 取消钉住 → 关闭浮动面板。

## 桌面交互（沿用上一版）

- 未钉住：悬停 150ms 切换，J/K/H/L 立即切换，离开卡片保留最后一张。单击卡片钉住，P 切换钉住，I 开关侧边栏。
- 打开 tab：↵、双击、卡片右上 ↗、侧边栏「打开 tab」。单击不再打开 tab。
- 卡片标记：当前 = mix(accent 7%, card) 底 + mix(accent 45%, border) 边；悬停 = mix(foreground 4%, card)；键盘焦点 = 2px accent 外环；钉住 = 当前标记 + 右上 accent pin。
- 状态变化、父 / 子任务跳转与返回、持久化 `betterPaseo.board.sidebar = { open, width }` 同上一版。

## 平板

- 沿用桌面阈值：iPad 1180 横屏内嵌；820 竖屏、840 折叠屏浮动；宿主侧栏展开（1180 时 B = 900）也浮动。
- 点按卡片即选中；侧边栏关着时以浮动面板临时显示，不改开关偏好。
- 打开 tab 用卡片右上 ↗ 或面板按钮，不用双击（否则每次点按都要等 300ms）。
- 关闭面板：面板内向右拖或点面板外。不做从屏幕右缘拖出（iPadOS、Android 占用边缘手势）。
- 行高 44，顶栏按钮 36、热区 44；接外接键盘时快捷键照常。

## 手机（390）

- 顶部四个泳道 tab 换成统计条（图标 + 数量），兼作泳道切换。
- 点按卡片打开详情 sheet（半屏 / 全屏两档），内容是同样的卡片堆叠；「打开 tab」是吸底主按钮（高 48，让出 34 安全区），运行中旁边是「停止」，待输入时是允许 / 拒绝 / 回答。卡片右上 ↗ 仍可直接打开 tab；长按改为上下文菜单。
- sheet 里左右滑切换同泳道的上一张 / 下一张。

## 动画

- 内嵌：打开 180ms cubic-bezier(0.2, 0, 0, 1)，关闭 120ms；泳道一次性跳到新宽度。
- 浮动面板：滑入 220ms、滑出 160ms。
- 手机 sheet：打开 280ms、两档切换 240ms、关闭 200ms。
- prefers-reduced-motion 只留短淡入淡出。

## 与要求不一致、需要确认的地方

- 圆形按钮按截图量得 28（用户说「36 左右」），桌面用 28、触屏 36。
- 按「340 + 两列」的规则，1024 宽仍内嵌（侧边栏缩到 368），浮动面板用 960 演示；要让 1024 也浮动需调高阈值。
- 交互变化：桌面单击由「打开 tab」改为「钉住」；手机点按由「打开 tab」改为「打开详情 sheet」，长按由「详情」改为上下文菜单。

## 移植前要核对

- 归档撤销、删除提示需要数据源区分归档和删除。
- 手机 sheet 两档高度和左右滑切换要在宿主的手势体系里验证（见 memory：宿主手势会抢插件的拖动）。
- 原稿 lucide 图标从网络加载，离线打开不显示。
- 「Desktop」等已开 tab 的客户端名、改动数量这些数据缺口同 task-details-popover.md。
