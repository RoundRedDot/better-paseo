## 结论

- 分档（B = 看板宽）：< 488 手机布局（已有）；488–760 sheet 档；784–996 浮动档；≥ 1020 内嵌。回差都是 24。
- sheet 档：详情是看板内的非模态底部 sheet，宽同看板，不加遮罩。有两档高度：半屏 = 泳道区高 × 0.58，全屏 = 泳道区高 − 8。头部卡固定，下面的内容区独立滚动。只有把手区和头部卡可以拖动来切换档位，sheet 不响应左右滑。点卡片：sheet 没开时打开，已开时原地换内容；点空白处、点 ✕、下拉、按 Esc 都会关闭 sheet。
- 顶栏只有一行（52）：状态条（兼泳道跳转；放得下时每格带名称，例如「运行中 3」，放不下时先把搜索框收成圆形按钮，再去掉名称，只留图标和数字）、已生效的筛选 chip（B ≥ 760 时显示）、搜索、「筛选」按钮，浮动档再加侧边栏开关。Workspace、Agent、标签、已完成时间窗、排序都收进筛选弹层（复用手机布局的 `FilterSheetBody`）。「98 个任务」标题去掉。sheet 档没有侧边栏开关。
- 泳道：每列宽 `clamp((B − 32) / 2, 220, 300)`，横向滚动时按列吸附。sheet 打开时，每列底部留出 sheet 的高度。
- 浮动档：面板只在需要时浮出，宽 `clamp(round(B × 0.36), 300, 360)`，跟着看板宽度走（784 → 300，873 → 314，996 → 359）。面板从侧边栏开关正下方开始（top = 48，右边和开关对齐），盖住筛选行的右半部分，不再盖住任何控件。面板里不放统计卡；没有选中时，面板里是分组卡。整个面板只有一个滚动容器，统计卡收成一行跟着滚走，头部卡吸顶。
