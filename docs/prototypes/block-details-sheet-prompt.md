请为 Paseo 的插件 Better Paseo 设计**会话详情页里 Block（时间线中的工具行）的详情面板**，覆盖从手机、平板到桌面的各种屏幕。这一稿用来替换手机上「长按 Block 弹出居中浮层」的做法，改成「单击 Block，从底部拉出抽屉」，交互参考插件里任务看板的详情 sheet。产出一份可直接查看、可精确移植的静态 HTML/CSS 设计稿。项目名称设为「Better Paseo · Block 详情抽屉」。

## 背景：会话时间线和 Block

会话详情页是一个 coding agent 会话的时间线：用户消息、助手正文，以及一行行工具调用（Block）。每个 Block 折叠时是一行，高度 28（紧凑模式 26）：
- 左边 16px chevron；
- 工具图标和标题，例如「npm run typecheck」「Read src/app.tsx」「Edit hover-preview.tsx +12 −3」；
- 右边是状态和时长，例如「✓ 4.3s」「812ms」，运行中显示跳动圆点。

展开后，行下面是 surface1 底、圆角 8 的正文块。正文按工具不同而不同：
- Bash：命令加输出，等宽字体；
- Read：带行号的代码；
- Edit：diff；
- 搜索：结果列表；
- Fetch：网页 Markdown；
- 子 agent：一段对话；
- 思考：Markdown；
- 提问：问答列表；
- todo：清单。

连续的同类调用会合并成一行，例如「Read 6 files」，预览里用分页器逐个翻看。没有正文的行不可展开、不出预览。

附件 timeline-rows-bash.png 和 timeline-rows-edit.png 是桌面浅色下展开的 Block。

## 现状：各设备怎么看 Block 详情

**桌面 Web（鼠标）**
- 悬停 1 秒（设置里可调 0–10 秒）后，在行下方弹出预览浮层：宽等于内容列宽，最高 360，下方放不下时改放上方，鼠标离开 150ms 后关闭。
- 浮层工具栏：
  - 左：换行开关、合并行的分页器，或「渲染 / 原文」切换；
  - 中：工具图标和名字；
  - 右：复制和最大化。
- 正文顶部是文件路径，下面是正文和错误。
- 可拖工具栏移动、拖 8 个边角缩放（最小 240×120）；可最大化到窗口内容区（上下各留 16）。
- 点外部、滚轮、Esc 时关闭。
- 单击行是原地展开 / 收起。
- 附件 preview-window-desktop.png 是最大化后的窗口样式。

**手机（iOS / Android 原生，390 宽）**
- 长按行 500ms，弹出居中浮层：透明 Modal 加 20% 黑色蒙层，居中在顶栏（64）和输入框（iOS 104、Android 120）之间；宽等于行宽，高随内容，最高是这段区域减去上下各 8。
- 可拖工具栏移动、拖边缩放，没有最大化和关闭按钮，点蒙层或按 Android 返回键关闭。
- 单击行仍是原地展开 / 收起。
- 读图片的行，长按直接打开图片查看器。

问题：
- 长按不好发现；
- 浮层又小又悬在中间，像个 tooltip，长输出和 diff 很难读；
- 拖动和缩放在手机上很别扭；
- 没有明确的关闭按钮。

**平板**
- iPad 原生和手机一样，是长按加居中浮层，宽屏下也只是一个窄窄的浮层，没有利用屏幕。
- iPad Safari 和手机浏览器完全没有预览，长按只会复制内容。

**参考交互**
附件 tasks-phone-sheet.png 是插件任务看板手机端刚定稿的详情 sheet：
- 点按卡片拉出底部 sheet，半屏和全屏两档，顶部有抓手；
- sheet 里能切换上一张 / 下一张；
- 主操作吸底，避开安全区。

已经实现的参数：
- 半屏是可用高度的 0.58，全屏是可用高度减 8；
- 顶部把手区高 28，抓手条 36×5，顶部圆角 16；
- 只有把手能拖：竖直拖超过 64px 或速度超过 0.5px/ms 就切档，半屏往下拖则关闭；
- 点把手在两档之间切换；
- 动画：打开 280ms、切档 240ms、关闭 200ms，缓动 cubic-bezier(0.2, 0, 0, 1)。

Block 详情抽屉请沿用这套语言，可以按内容需要调整。

## 需要你设计并说明的

1. **手机上的点击模型。** 用户要求单击 Block 打开底部抽屉，这和现在的「单击原地展开」冲突，请给出方案并说明理由。可选方向：
   - 单击行身打开抽屉，chevron 区（热区 44）仍是原地展开；
   - 单击一律开抽屉，抽屉里提供「在时间线中展开」；
   - 或更好的方案。

   长按要不要保留、改成什么，例如复制菜单，或不做任何事。没有正文的行点了怎么反馈。
2. **抽屉本体。**
   - **档位**：半屏和全屏两档，还是按内容高度自适应、再加全屏。短输出（3 行）和长输出（2000 行）各是什么样。
   - **头部**：抓手、工具图标、标题（完整换行还是单行截断）、状态和时长、关闭按钮。
   - **工具栏**：换行、复制（不同工具复制的东西不同，如命令、输出、路径、diff）、渲染 / 原文、合并行分页器。原来桌面的「最大化」在抽屉里对应什么。
   - **正文**：文件路径、代码行号和隔行底色、diff、Markdown、错误信息的排法。
   - **运行中的 Block**：流式输出时跟随到底部，用户上滑后停止跟随，并给出「回到最新」的方式。
3. **在抽屉里切换 Block。** 像任务 sheet 一样切换上一个 / 下一个 Block（左右滑或头部箭头），切换范围是整个会话的可预览 Block，还是同一轮回复内。切换时时间线是否同步滚动到对应行，以及当前行的标记。
4. **手势冲突。** 代码关掉换行后可横向滚动，这和左右滑切换 Block 冲突；纵向滚动正文和下拉关闭抽屉也冲突。请给出明确的规则，例如：
   - 只有把手和头部能拖动抽屉；
   - 正文滚到顶后再下拉才带动抽屉；
   - 横向滑只在头部区域切换。
5. **平板**，请重新设计，不要只是放大的手机抽屉。需要覆盖：
   - iPad mini 竖屏 744×1133；
   - iPad 11 寸竖屏 834×1194、横屏 1194×834；
   - iPad 13 寸横屏 1376×1032；
   - 安卓折叠屏展开约 840×900；
   - 台前调度 / 分屏下的窄窗口（约 500 宽）。

   宿主左边可能展开 agent 列表侧栏（约 280），这时会话区更窄。可能的方向：
   - 会话区够宽时，详情作为右侧面板，盖在会话区右侧，高度贴满，时间线留出可读区；
   - 不够宽时，用底部抽屉，或居中的 form sheet（宽约 540–600）。

   请给出按「窗口宽 W」划分的阈值和回差。iPad 接触控板或外接键盘时的行为：是否支持悬停、方向键切换、Esc 关闭。
6. **桌面。** 悬停预览已经被用户接受，原则上保留。请考虑：
   - 单击要不要也能打开一个固定的详情面板（例如右侧面板，和平板宽屏一致），从而统一「单击 = 详情」的心智；
   - 还是保持「单击 = 原地展开、悬停 = 预览」，只调整视觉。

   给出 1280 和 1920 宽两种窗口下的样子。窄窗口（< 760）的桌面浏览器是否切换成抽屉。
7. **触屏 Web**（手机 Safari、iPad Safari）：现在没有预览，请让它和原生同一套交互。
8. **断点总表**：按输入方式（触屏 / 鼠标）和窗口宽，列出每一档用哪种形态（底部抽屉 / form sheet / 右侧面板 / 悬停浮层），以及切换时已打开的面板怎么过渡。
9. **动画**：打开、切档、关闭、切换 Block 的时长和缓动；prefers-reduced-motion 时只保留短淡入淡出。

## 实现约束

- 最终用 React Native（含 Web）的 flexbox 实现。
- **图层**：插件不能改宿主布局。在时间线上能盖住内容的只有一个全屏透明 Modal，所以「右侧面板」实际上是 Modal 里贴右边的一块，背后的时间线不会变窄。
  - 请设计面板背后要不要蒙层，以及蒙层能否点穿去点别的 Block 直接切换。如果要点穿，就只能不加蒙层、背后可点，请说明你的选择。
  - Web 端插件可以在页面任意位置画层，不受此限制。
- **手势**：手机上宿主的列表滚动和右滑打开 agent 列表会抢手势，抽屉的拖动区要明确、集中在把手和头部。没有触感反馈可用。
- **安全区**：iOS 底部安全区 34；Android 返回键关闭抽屉。
- **颜色**：宿主主题任意，插件只能拿到这些颜色 token：surface0、surface1、surface2、border、foreground、foregroundMuted、accent、success、warning、danger。新颜色请写成 token 推导公式，并给出浅 / 深两套参考值。
  - 浅色：surface0 #ffffff、surface1 #f6f6f7、surface2 #ededef、border #e2e2e6、foreground #18181b、foregroundMuted #62626b、accent #2563eb、success #1f8a5b、warning #a36a00、danger #d92d20。
  - 深色：surface0 #0f0f11、surface1 #17171a、surface2 #1f1f23、border #2a2a30、foreground #f2f3f5、foregroundMuted #a3a6ad、accent #7aa2f7、success #4cb782、warning #e0a84a、danger #f2555a。
- **图标、字体与视觉**：
  - 图标只用 lucide；Paseo 的线条粗细是 1.5，插件的图标要一致。
  - 字号下限 11px，不新增字体，等宽字体用系统等宽。
  - 不要渐变，也不要彩色整块底色。
- **行和按钮**：
  - 行高沿用 28 / 26，触屏热区不小于 44。
  - 顶栏圆形按钮桌面直径 28，触屏 36。
