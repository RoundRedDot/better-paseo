现状规格（交互保持不变，只改视觉与动效细节）：
- 位置：控件左上角对齐表格容器左上角，表格本身向右、向下各让出 12px，所以控件压在表格外框的左上角上；控件背后垫一块与控件同形状的页面底色（surface0），遮住被压住的表格边框。
- 收起：24×24 圆形，1px 边框（border 色），底色 surface0，中间 14px 线性复制图标（Lucide「Copy」，muted 色）。
- 展开：鼠标移入后，同一个外框向右拉长成胶囊（高 24、圆角 12），里面两项：[Copy 图标 + 「复制为 Markdown」] | 1×12 分隔线 | [Image 图标 + 「复制为图片」]。文字 12px 界面字体、行高 16、正文色；图标 14px muted 色；图标与文字间距 4；第一项左内边距 4（让图标正好落在收起圆形的中心），右 8；第二项左 8、右 10。展开时外框边框换成 muted 色。
- 悬停某一项：该项铺 surface2 底色（被胶囊外框裁成圆头）。按下同悬停。
- 已复制：被点的那一项图标换成对勾（Lucide「Check」，正文色）1.2 秒，同时弹出系统 toast「已复制为图片」。失败只弹 toast「复制失败」，不显示对勾。
- 动画：外框宽度 24 → 约 226 的 CSS transition，180ms，cubic-bezier(0.33, 1, 0.68, 1)；文字与分隔线同时淡入，边框色同时过渡；移出时反向收回，可中途打断。系统开启「减少动态效果」时时长为 0。
- 菜单只在桌面（可 hover 的指针）出现；触屏仍是单个圆形按钮，点击复制 Markdown。

2. 展开的菜单要像一个浮在表格之上的轻量操作条，与被压住的表头文字区分清楚，但不喧宾夺主。
3. 收起状态是一个安静的小圆形，平时不抢正文；展开后两项的可点区域与当前项要一目了然。
4. 动效：在现有 180ms 宽度过渡的基础上，给出你认为更好的细节（各属性的时长、缓动、先后顺序、文字是否带轻微位移等），但总时长不超过 220ms，不要回弹或缩放，移出必须同样顺滑且可中途打断。
