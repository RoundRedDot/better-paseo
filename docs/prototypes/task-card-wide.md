- 来源：[Claude Design 项目「Better Paseo · 宽列任务卡片」](https://claude.ai/design/p/35a4ced7-2b37-42ce-ba00-d3fa71060047)

- 提示词：[task-card-wide-prompt.md](task-card-wide-prompt.md)。附图：用户的 2000px 看板截图 `board-desktop-2000.png`，以及「运行中」「已完成」两列卡片的放大裁图。
- 原稿 SHA-256：`12dd6e51b1f1f7e541d477f3ad5a6c517c1152c3d656612bdbed7bd061d473da`

用户的要求：桌面端各列平分宽度、没有上限，卡片在 2000px 窗口里约 470px 宽，内容全部左对齐、逐行堆叠，右半边空白，显得松散。要求充分利用横向宽度，同时保持卡片精致。原稿四块画板：2000px 看板现状与新设计对照、单卡 284/380/470/620/860px × 六种场景（浅、深）、宽档交互态、移植规格。

## 分档

- 窄档 < 380：保持现状。
- 宽档 380–599：三行。
- 超宽档 ≥ 600：左侧内容封顶 600，右侧元数据贴右缘，多出的空白放在两者之间。
- 阈值两侧各留 8px 缓冲，拖动窗口时不来回跳。380 是一行刚好放下「模型 + 思考强度 + 截断后的分支」的宽度；600 时一行约 44 个汉字，大多数标题一行放完。

## 宽档结构（含边框 92px，现状 120，折行时 150）

1. meta 行：左「项目 › ↳ 父任务」，右「workspace · worktree」，最右 ↗。
2. 标题行：状态图标 + 标题，最多 2 行。
3. chip 行：左 chips（单行，不折行），右计时，最右上下文环。

内边距 10/12/10，行间距依次 4、8。

对齐线（W 为卡片宽）：图标槽 x 12–26（项目图标、状态图标、附加块图标）；G = 32（项目名、标题、chips、附加块文字的左缘）；R = W−38（右上元数据、计时、子任务计时、Stop 的右缘）；尾槽 W−32…W−12（↗ 和上下文环共用竖轴）。

## 收缩与截断

- chips：分支截断到 140 → 标签收成「首个 + +N」→ 隐藏思考强度 → 隐藏 git 状态 → 标签只留数量 → 分支截断到 72 → 模型只留品牌标。PR 和子任务不隐藏。
- meta 行：↳ 父任务 → workspace → worktree → 项目名（最小 40）。完整路径从头部截断，保留末段。
- 原稿按文字宽度估算收缩步骤；实现时应测量每个 chip 的真实宽度。

## 附加块与交互

- 权限按钮和标题同一行贴右；失败原因单行；子任务列表的计时对齐 R 线。
- 悬停 Stop 绝对定位 top 8 / right 38，左侧用同色实色阴影盖住下面的文字；焦点为 accent 边框 + 3px 光环；都不引起位移。
- 新增「最近输出」一行：只在运行中列、宽度 ≥ 600 时出现，新增设置开关，默认开。未加 diff 统计（分支 chip 已有 git 状态）。

## 颜色（浅 / 深）

- hover = mix(fg 4%, card)：`#f6f6f6` / `#29292d`
- chip = mix(fg 6%, card)：`#f1f1f1` / `#2e2e32`
- accentSoft = mix(accent 10%, card)，深色 16%：`#e9f0fd` / `#2e3549`
- focusRing = accent 28% 透明度，深色 35%

宽档的模型 chip 改为中性底加彩色品牌标（窄档仍是品牌色浅底）；原稿的品牌标用 lucide 临时代替。

## 移植前要核对

- 渲染检查发现：2000px 看板里 ideashell-android 的卡片，meta 行右侧只剩 worktree，workspace 名（如「Android 对齐 2.0.6：note」）被隐藏，而父任务保留，与它自己写的截断顺序（父任务先让位）不一致。
- 「最近输出」需要运行中 agent 的最近一条输出，`TaskCard` 现在没有这个字段。
- 用户随后改为先做详情侧边栏（见 task-details-sidebar-prompt.md），这一稿尚未定为实现方案。
