正文

全屏档

规则
可用高 = 屏高 − 顶部安全区（iPhone 47）。初始档 = min(内容高, 0.58 × 可用高)。半屏或自适应档下拖 > 64 或 v > 0.5 → 关闭（200ms）。切换 Block 时保持当前档；若新内容更短，自适应高度用 240ms 过渡；全屏档不随内容变矮。运行中的 Block 内容增长时，自适应档跟着长高，到 0.58 封顶。
