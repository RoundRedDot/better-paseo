抽屉档位怎么定
短输出撑不满半屏时，固定半屏会留下大片空白，还挡住时间线。改成按内容适配：
•初始高度取内容高度与 0.58 倍可用高度中较小的一个；
•内容超过半屏才提供全屏档；
•全屏档顶部留 8，和任务 sheet 一致。
切换 Block 时如果两档高度不同，高度用 240ms 过渡，避免跳动。
手势分区
把手和头部负责拖动抽屉和横滑切换，正文只负责滚动。正文滚到顶后继续下拉，才把手势交给抽屉。
const initial ⁠= Math.min(fitHeight, avail * 0.58); const full ⁠= avail - 8;
横向滑动在正文里只滚代码，永远不切换 Block。

Modal
Modal 用于在当前视图之上展示内容。透明 Modal 不会遮住背后的视图。
常用属性
•transparent：背景透明，背后内容可见。
•onRequestClose：Android 返回键时调用，需要在这里关闭。
•animationType：none、slide 或 fade。
•statusBarTranslucent：内容延伸到状态栏下方。
注意
Modal 在 iOS 上会占据整个窗口，背后视图的触摸取决于内容的 pointerEvents。
