## 数据来源

所有数值都按 `docs/bench/2026-10-17-readme/parallel-v2/raw/web` 的 5 次中位数重新计算，与 README 一致：Better Paseo `b9dfae6`、Beautiful Chat `42b61d8`。

- 竞速：长回复 Web 整段回放主线程 Task 时间，不开插件 4.77 s、Beautiful Chat 5.58 s、Better Paseo 2.75 s，相对两者分别减少 42.5% 和 50.8%。条长按比例匀速增长，动画时长不是实时计时。
- 数据卡：代码块流式行渲染总量 828 → 147 ms（减少 82%，对比不开插件；宿主 Profiler 累计值，不代表帧率）；长回复累计布局偏移 0.183 → 0.000015（对比不开插件，取自 README 的 CLS 表）；读 20 个文件 JS 堆 232 → 108 MB（省 123.5 MB，对比 Beautiful Chat）。
- 计分板：Web Task 对比不开插件 9 项更低、2 项持平、0 项更高；对比 Beautiful Chat 10 项更低、1 项持平、0 项更高。持平指相差不到 10%，或双方都低于 0.5 秒。

画面底部持续标注指标口径、版本和「动画按比例示意」。增长箭头沿用 README 样式：绿色 ⬆ 表示更好。
