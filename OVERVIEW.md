Better Paseo puts every agent on one Tasks board across your phone, pad, and desktop. It also redraws conversations as compact rows for tool calls, reasoning, replies, prompts, checklists and errors.

Tool calls start collapsed. The timeline offers syntax highlighting, streaming Markdown, block details, previews and copying, including table-cell selection. The Tasks board supports search and filters, agent details, stop and archive actions, permission responses, and manual or model-generated titles. Available actions and selection controls vary by platform and host capabilities.

## Setup and settings

Paseo 0.14.0 or later is required. Settings control reply rendering, fonts, previews, translation and the Tasks board. Translation uses free public machine translation (Microsoft, Google or Tencent TranSmart) by default, or a user-configured OpenAI-compatible endpoint and model; automatic title generation has its own provider and model settings. Mermaid code blocks use Paseo’s diagram renderer after the fence closes or the reply ends. Turning off plugin Markdown returns the whole reply to Paseo, including its file links.

## Data access and limits

The plugin reads displayed conversations, tool results, agent metadata and host appearance settings. Syntax highlighting sends displayed code to the daemon. Image previews can read files on the daemon; desktop file links can open files or reveal them in the file manager. Presentation and most board settings are shared by clients connected to the daemon.

When title generation is requested, excerpts of the conversation and the configured prompt are sent to a helper agent. By default it uses the provider, model and thinking level of the card's agent; the selected model is used only when Custom automatic title model is turned on. The helper uses the provider's configured permissions; the instruction not to use tools is not a sandbox. The plugin records recent turn timing, token usage and errors on the daemon and reads provider session files for available running token counts. Some board actions use the Paseo CLI or a local daemon connection and are unavailable when those capabilities are missing.

Translation runs only when you press Translate. In free mode, the client sends the selected text straight to the chosen service (Microsoft by default), without a key and without going through the daemon; code blocks are not sent, and inline code, links and URLs are swapped for placeholders. These are the unofficial endpoints browser translators use, with no service guarantee. In OpenAI-compatible mode, the Paseo daemon sends the selected text or whole reply or task-detail section, target language and translation prompt directly to the OpenAI-compatible endpoint configured in Better Paseo settings. Requests do not provide tools; tool calls in responses are rejected and never executed. In that mode, translation remains unavailable until an endpoint and model are configured. The optional API key is stored unencrypted in a file on the daemon host, protected by that host's file permissions, and is sent only to the origin for which it was saved. The endpoint service handles the submitted data according to its own policies. The plugin server and client cache translation results in memory.
