Better Paseo puts every agent on one Tasks board across your phone, pad, and desktop. It also redraws conversations as compact rows for tool calls, reasoning, replies, prompts, checklists and errors.

Tool calls start collapsed. The timeline offers syntax highlighting, streaming Markdown, block details, previews and copying, including table-cell selection. The Tasks board supports search and filters, agent details, stop and archive actions, permission responses, and manual or model-generated titles. Available actions and selection controls vary by platform and host capabilities.

## Setup and settings

Paseo 0.14.0 or later is required. No separate service account is needed. Settings control reply rendering, fonts, previews, translation and the Tasks board, including an optional provider, model and prompt for title generation and for translation. Mermaid code blocks use Paseo’s diagram renderer after the fence closes or the reply ends. Turning off plugin Markdown returns the whole reply to Paseo, including its file links.

## Data access and limits

The plugin reads displayed conversations, tool results, agent metadata and host appearance settings. Syntax highlighting sends displayed code to the daemon. Image previews can read files on the daemon; desktop file links can open files or reveal them in the file manager. Presentation and most board settings are shared by clients connected to the daemon.

When title generation is requested, excerpts of the conversation and the configured prompt are sent to a helper agent. By default it uses the provider, model and thinking level of the card's agent; the selected model is used only when Custom automatic title model is turned on. The helper uses the provider's configured permissions; the instruction not to use tools is not a sandbox. The plugin records recent turn timing, token usage and errors on the daemon and reads provider session files for available running token counts. Some board actions use the Paseo CLI or a local daemon connection and are unavailable when those capabilities are missing.

Translation runs only when you press Translate. It sends the text you chose (selected text from a reply, reasoning, tool output or task details, or a whole reply or task-detail section) to a helper agent on the daemon, together with the target language, the translation prompt and fixed instructions. By default the helper uses the conversation's provider and model; with Choose provider and model turned on it uses the configured ones. That provider receives the text and handles it as it handles any other prompt, which can mean sending it to the provider's service. The helper starts in an empty plugin folder without project files or instructions, and is deleted afterwards. It must run with no tools at all: the plugin sends the text only after the daemon reports tool-free agent support, the provider reports that it enforces it, and the created helper is confirmed tool-free. The translation settings list only providers that can run this way. On Paseo versions or providers that cannot confirm all three, nothing is sent and Translate shows an error; the plugin does not fall back to another provider. The plugin server and the client keep results in memory only.
